# NodeJS Basics Assignment

This repository contains basic Node.js programs demonstrating how to create and execute Node.js applications and print outputs in the terminal using `console.log()`.

## Folder Structure

```text
NodeJS-Basics-Assignment
│
├── app.js
├── introduction.js
└── README.md
```

---

## Assignment Tasks

### Task 1: Your First Node.js Program
- **File:** [`app.js`](app.js)
- **Description:** A simple Node.js program that prints welcome and learning messages in the terminal.

#### Code
```javascript
console.log("Hello, Node.js!");
console.log("I am learning backend development");
```

---

### Task 2: Create a Simple Introduction Program
- **File:** [`introduction.js`](introduction.js)
- **Description:** A Node.js program that displays personal introduction details such as Name, Education, Current Learning, and Goal using `console.log()`.

#### Code
```javascript
console.log("Name: Ankitraj Jha");
console.log("Education: B.Tech");
console.log("Current Learning: Node.js");
console.log("Goal: Developer");
```

---

## Steps to Run the Programs

1. Open your terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd NodeJS-Basics-Assignment
   ```
3. Run the individual programs using Node.js:
   - For Task 1:
     ```bash
     node app.js
     ```
   - For Task 2:
     ```bash
     node introduction.js
     ```
